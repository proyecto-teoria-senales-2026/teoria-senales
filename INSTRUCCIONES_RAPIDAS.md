# Iniciar C3-3 en Windows

## Primera vez

1. Descarga la rama `c3-3-interfaz` desde **Code > Download ZIP**.
2. Extrae completamente el ZIP.
3. Abre la carpeta extraída.
4. Haz doble clic en **INICIAR_C3-3.bat**.
5. Espera mientras se instalan los componentes. La aplicación se abrirá en el navegador.

No cierres la ventana negra mientras estés usando la herramienta.

## Siguientes veces

Abre la carpeta y haz doble clic nuevamente en **INICIAR_C3-3.bat**.

## Si Windows muestra una advertencia

Pulsa **Más información > Ejecutar de todas formas** únicamente si descargaste el archivo desde el repositorio oficial del proyecto.

## Requisito

El computador debe tener Python 3.12 o 3.13 instalado y disponible en el PATH.
